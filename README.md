# Fleetly website

Static site for fleetlybots.com — three pages, no build step.

- `index.html` → https://fleetlybots.com (waitlist)
- `beta/index.html` → https://beta.fleetlybots.com (beta signup)
- `setup/index.html` → https://setup.fleetlybots.com (AI setup page)

Hosted on Cloudflare Workers (Static Assets), deployed from this repo.
